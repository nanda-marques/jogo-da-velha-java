**Jogo da Velha em Java**  
Este projeto implementa o clássico jogo da velha (tic-tac-toe) em Java, jogado no console. O jogador enfrenta o computador, que realiza jogadas aleatórias.  

### Funcionalidades
- Tabuleiro 3x3 exibido no console.  
- Jogador usa `X` e o computador usa `O`.  
- Verificação automática de vitória, derrota ou empate.  
- Placar acumulado entre rodadas.  
- Possibilidade de jogar várias partidas em sequência.  

### Como executar
1. Compile o código:
   ```bash
   javac JogoDaVelha.java
   ```
2. Execute o programa:
   ```bash
   java JogoDaVelha
   ```

### Objetivo
Este projeto foi desenvolvido para praticar lógica de programação, uso de vetores e estruturas de controle em Java.
